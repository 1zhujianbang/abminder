规则速查

目标：配牌区凑出两张同色牌并结算，个人分先到 5 分即获胜（多人同时到 5 则共同获胜）。

回合：每回合必须且只能行动一次：执行一次免费动作（移动 / 替换 / 翻转，不消耗手牌），或打出一张手牌（配对 / 固定 / 移除）。第 2 轮起回合开始抽 1 张手牌并刷新抽牌区。

六种行动：移动（把牌放进空槽）、替换（顶掉有牌槽的牌）、翻转（翻任意未固定颜色牌，翻面后该牌变固定；翻自己的固定牌则翻面并取消固定）、配对（两槽有牌时结算）、固定（保护一张非固定牌；固定牌不能被别人选为目标，但主人可以主动用它移动/替换/翻转，还能移进别人的空身份区）、移除（弃掉任意颜色牌）。

身份牌：每人一张，当前朝上颜色 = 得分颜色；身份区可为空（无颜色、不能得分）；任意玩家都能移动 / 替换 / 翻转 / 固定 / 移除身份牌。

响应：打出配对后立即进入响应窗口，所有玩家按座位顺序直接参与（不暗置）：每人可执行一次免费动作（目标限配牌区或身份牌；其他玩家的固定牌不可作为目标），或打出一张手牌【固定】/【移除】（目标限配牌区或身份牌），也可以跳过；响应结束后再比较颜色。

计分：配对成功后，身份区不为空且当前颜色与配对颜色相同的所有玩家个人分 +1。

操作：先点手牌或免费动作，再直接点场上的高亮目标；也可以把自己的抽牌区 / 任意身份牌拖到配牌槽或身份区（执行免费动作），或把手牌（配对 / 固定 / 移除）直接拖到场上高亮目标执行。下方按钮列表始终可用（键盘操作兜底）。

规则速查

目标

配牌区两个槽都有牌时可打出「配对」。结算时两张牌当前朝上的颜色相同即配对成功：身份区不为空、且身份牌当前颜色与该颜色相同的所有玩家个人分 +1。任意玩家个人分先到 5 分即结束对局；同一次结算多人同时到 5 则一起获胜。

回合流程

第 2 轮起，回合开始先抽 1 张行动牌（手牌上限 4），再刷新抽牌区（固定牌保留，按固定数量补抽到 3 张）。随后必须且只能执行一次行动：打出一张手牌（配对 / 固定 / 移除），或执行一次免费动作（移动 / 替换 / 翻转）。没有任何合法行动时跳过本回合并弃 1 张手牌。

操作方式

先点击手牌或免费动作，再直接点击场上高亮的合法目标即可执行（移动 / 替换为两步：先点高亮的来源牌，再点落点）。也可以把自己的抽牌区牌、任意玩家的身份牌拖拽到高亮的配牌槽 / 身份区上执行免费动作；手牌（配对 / 固定 / 移除）同样可以直接拖到场上高亮目标执行（配对可拖到任一配牌槽），拖拽执行后手牌照常消耗。所有操作都同时保留下方按钮列表，可用键盘完成；拖拽只是快捷方式，不是唯一操作方式（触屏请使用点击）。

六种行动

  • 移动（免费）：把自己抽牌区的牌或任意玩家的身份牌移进空槽（配牌区空槽，或抽牌区的牌放进任意空身份区）。
  • 替换（免费）：用自己抽牌区的一张牌替换有牌槽（配牌区或任意身份区），旧牌进颜色弃牌堆。
  • 翻转（免费）：翻任意未固定颜色牌（身份牌、抽牌区的牌、配牌区的牌），翻面后该牌变为固定；翻自己的固定牌则翻面并取消固定（其他玩家的固定牌不能翻）。
  • 配对（手牌）：配牌区两槽都有牌时打出，先进入响应窗口，结束后再比较颜色。
  • 固定（手牌）：固定任意一张非固定颜色牌；固定牌不能被别人选为目标，但主人可以主动用它移动 / 替换 / 翻转，主动使用后固定消失；牌仍可被移除。
  • 移除（手牌）：把任意一张颜色牌（含固定牌、身份牌）放进颜色弃牌堆。

身份牌与空身份区

每名玩家有一张身份牌，当前朝上的颜色就是得分颜色；身份区可以为空，此时该玩家没有得分颜色、配对成功也不会得分。身份牌可以被任意玩家移动、替换、翻转、固定、移除；身份区为空时可以用「移动」从自己抽牌区放一张牌进去。

响应窗口

打出配对后立即进入响应窗口，配牌区两张牌保持不动。所有玩家都参与、不需要暗置：从打出配对者的上家开始按座位顺序询问，每人一次，可以执行一次免费动作（移动 / 替换 / 翻转，目标只能是配牌区或身份牌），或打出一张手牌【固定】/【移除】（目标限配牌区或身份牌；手牌会被消耗），或选择不响应；不能打【配对】。人类响应时牌桌进入响应交互模式：可以直接点击 / 拖拽场上高亮目标，也可以用响应条按钮；询问结束后结算配对：同色成功、异色失败、不足两张无效，配牌区清空。
